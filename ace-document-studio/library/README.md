# Shared library documents

Ready-to-import Ace Document Studio documents, one JSON file each, with a
PNG preview beside it. To add one to the store library:

1. Download the `.json` file to any store computer.
2. In Ace Document Studio, **File → Import Documents…** and pick the file.
3. Sync (File → Sync Settings…) pushes it to every other computer on the
   next poll, so import it on one computer only.

Importing never overwrites an existing document — a second import lands as
a copy with a new id.
