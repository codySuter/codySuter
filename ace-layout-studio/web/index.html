Ace Layout Studio — help

Tools (V H L D E X)
Select moves & box-selects · Pan scrolls the floor · Label types codes with one click per unit · Copy drags a duplicate off a unit · Extend drags matching panels out along an aisle · Erase removes units. Esc returns to Select.
Place fixtures
Drag from the palette, or click a palette item and stamp on the floor (Esc stops).
Extend a run
With the Extend tool, press on a panel and drag along the aisle — flush copies stamp out as you go.
Move
Drag units — they snap to a 1" grid and to the edges of nearby units. Hold Alt to disable edge snapping.
Exact gaps
Select a unit and click any red gap measurement to type the distance (e.g. 42 or 3' 6").
Label
Double-click a unit (any tool) to type its location code, or use the panel on the right.
Auto-number a run
Type a code (e.g. 01R01), then with the Label tool press on that unit and drag across the rest — each one it touches gets the next code (01R02, 01R03…). Zero padding is kept, and a trailing letter steps too (BAY-C → BAY-D).
Label look
Turn a label 90° with Shift+R (or ⟲ Turn) and size the text with [ / ] — per unit, and applies to the whole selection at once.
Multi-select
Drag a box on empty floor, or Shift-click. Ctrl+A selects all.
